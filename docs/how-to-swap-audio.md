# 怎麼替換網站的音訊

這個網站播放兩種音訊，都是很單純的 `<audio>` 元素，由 `src/components/` 底下的元件渲染，實際檔案放在 `public/audio/`：

- **背景音樂**（`AmbientAudio.astro`）— 持續播放的背景音樂，目前是 `public/audio/ambient.mp3`。
- **雪地環境音**（尚未加入，另外追蹤中，不在這份文件的範圍）— 疊加在背景音樂上的第二軌持續音，`public/audio/snow-ambience.mp3`。

這兩個都用同一套替換方式，因為檔名本來就取得很通用（`ambient.mp3`、`snow-ambience.mp3`），沒有用曲名命名——換檔案就是整個操作的全部，不需要動任何程式碼。

## 怎麼換一首歌

1. 準備好你要換上去的音訊檔案。如果還沒有，可以看下面「去哪裡找音樂」那段。
2. 把檔名改成跟你要取代的檔案完全一樣：
   - 背景音樂用 `ambient.mp3`
   - 雪地環境音用 `snow-ambience.mp3`
3. 把它複製到 `public/audio/`，直接覆蓋掉原本的檔案。
4. 這樣就完成了——沒有任何元件程式碼會寫死曲名，所以不需要再改別的地方。重新整理網站（或重新部署）就會聽到新的音樂。

## 檔案格式與大小

- **格式**：`.mp3`。兩個 `<audio>` 元素的 `src` 都寫死成 `/audio/....mp3`——如果你想改用 `.ogg` 或 `.wav`，就不能只是丟檔案進去，還要去改元件裡的 `src` 屬性。
- **大小**：目前的 `ambient.mp3` 大概 8.4MB，已經是整個網站裡最大的一個資源檔了。它是延遲載入的（`preload="none"`，要等訪客第一次點擊/按鍵之後才會開始載入），所以不會擋到頁面的初始載入，但檔案如果換得更大，音樂真正開始播放前要等的時間也會拉長。新的曲子盡量控制在差不多的大小範圍內；這裡沒有寫死任何硬性限制，純粹是為了照顧網速比較慢的訪客。

## 授權注意事項

目前這首 `ambient.mp3` 其實是一首商業遊戲原聲帶的曲子，不是原創或已經取得授權的內容——這是在這個個人網站上刻意接受的一個已知風險，記錄在 `docs/adr/0005-ambient-soundtrack-and-utility-pages.md` 裡，但**沒有被解決**。那份 ADR 並不要求你換歌的時候一定要順便解決這個問題，但既然都要選新的曲子了，剛好是個好時機，優先選一首你真的有權利使用的——例如 Creative Commons 授權、免版稅（royalty-free）的曲子、自己做的音樂，或是你已經買好對應授權的曲子。可以參考幾個地方：

- [Pixabay Music](https://pixabay.com/music/) — 免版稅，不需要標註來源
- [Free Music Archive](https://freemusicarchive.org/) — 可以依授權條件篩選，不少曲子需要標註來源
- [incompetech.com](https://incompetech.com/)（Kevin MacLeod）— 免版稅，但需要標註來源

不管選哪一首，記得去該曲目頁面確認清楚實際授權條款——「免費」不代表「可以商用」，也不代表「不用標註來源」。
